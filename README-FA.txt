پروژه اپلیکیشن آگهی چهاردانگه

این پروژه یک اپلیکیشن Android WebView است که سایت https://www.agahi4dangeh.ir را داخل اپ نمایش می‌دهد.
قابلیت‌ها: JavaScript و DOM Storage برای ورود و نشست کاربر، انتخاب فایل برای بارگذاری عکس، لینک‌های تماس/ایمیل و دکمه برگشت.

روش بارگذاری در GitHub:
1) فایل ZIP را در رایانه Extract کنید.
2) در مخزن agahi4dangeh-android گزینه Add file > Upload files را بزنید.
3) همه فایل‌ها و پوشه‌های داخل پوشه agahi4dangeh-android را انتخاب و در ریشه مخزن بارگذاری کنید (خود پوشه والد را داخل مخزن قرار ندهید).
4) Commit changes را بزنید.
5) در تب Actions اجرای Build Android APK را باز کنید. پس از موفقیت، از بخش Artifacts فایل agahi4dangeh-debug-apk را دریافت کنید.

نکته: خروجی فعلی Debug APK برای تست و نصب مستقیم است. برای انتشار رسمی در کافه‌بازار/مایکت باید نسخه Release با کلید امضای اختصاصی ساخته شود. پیش از انتشار، مجوزها، سیاست حریم خصوصی و رفتار ورود/آپلود در سایت واقعی تست شوند.
