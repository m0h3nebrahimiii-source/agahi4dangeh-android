اپلیکیشن اندروید آگهی چهاردانگه — نسخه ۲.۴.۵
================================================

این پروژه یک اپلیکیشن اندرویدی سبک بر پایه WebView است و وب‌سایت اصلی را با امکانات موبایلی باز می‌کند.

وب‌سایت: https://agahi4dangeh.ir/
شناسه برنامه: ir.agahi4dangeh.app
نسخه: 2.4.5
حداقل اندروید: Android 6.0 (API 23)
مبنای ساخت: Android Gradle Plugin 8.7.3 / Gradle 8.9 / JDK 17

امکانات پیاده‌سازی‌شده:
- نمایش وب‌سایت درون برنامه
- پشتیبانی از JavaScript و Local Storage برای ورود و نشست کاربر
- انتخاب فایل/تصویر از فرم‌های سایت
- مدیریت دکمه بازگشت اندروید
- نمایش نوار پیشرفت و صفحه خطای اتصال با امکان تلاش مجدد
- باز کردن پیوندهای خارج از دامنه در برنامه مناسب گوشی
- پشتیبانی از دانلود فایل‌های سایت
- نوار وضعیت سرمه‌ای و هویت بصری سرمه‌ای/طلایی

ساخت APK با GitHub:
1) فایل ZIP را استخراج کنید.
2) محتویات پوشه پروژه را در ریشه مخزن GitHub با نام agahi4dangeh-android قرار دهید.
3) فایل‌های قدیمی مخزن را با همین فایل‌های پروژه جایگزین کنید؛ پوشه .github نیز باید جایگزین شود.
4) تغییرات را روی شاخه main ثبت (Commit) و Push کنید.
5) در GitHub وارد Actions شوید و اجرای Build Agahi Chahardangeh APK را باز کنید.
6) پس از موفقیت، از بخش Artifacts فایل agahi-chahardangeh-android-v2.4.5 را دریافت کنید.

نکته مهم:
- این پروژه به سورس قالب وردپرس نیاز ندارد؛ اپلیکیشن مستقیماً سایت زنده را نمایش می‌دهد.
- شماره نسخه برنامه ۲.۴.۵ است تا با نسخه قالب اعلام‌شده هماهنگ باشد؛ این به معنی کپی شدن فایل‌های قالب در APK نیست.
- این ZIP سورس کامل پروژه و گردش‌کار GitHub Actions است، نه فایل APK نهایی.
- در محیط ساخت فعلی Android SDK و Gradle نصب نیست و دسترسی شبکه برای دریافت آن‌ها وجود ندارد؛ بنابراین ساخت واقعی APK در این محیط اجرا نشده است. Workflow در GitHub ساخت APK را انجام می‌دهد.
