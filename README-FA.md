# اپلیکیشن آگهی چهاردانگه

این پروژه یک پوسته اندرویدی ساده مبتنی بر WebView است که وب‌سایت زیر را درون برنامه نمایش می‌دهد:

`https://www.agahi4dangeh.ir/`

## ساختار
- `app/`: کد و منابع اپلیکیشن
- `.github/workflows/android.yml`: ساخت خودکار APK در GitHub Actions
- `build.gradle` و `settings.gradle`: تنظیمات Gradle

## ساخت APK در GitHub
1. تمام محتویات این پوشه را (نه خود پوشه والد) در ریشه مخزن GitHub بارگذاری کنید.
2. نام شاخه اصلی را `main` بگذارید.
3. از زبانه **Actions** اجرای **Android Build** را باز کنید.
4. پس از موفقیت، از بخش Artifacts فایل `agahi-chahardangeh-debug` را دریافت کنید.

## نیازمندی‌ها
- JDK 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3
- Android SDK Platform 35

## محدودیت‌های این نسخه
این نسخه سایت را با WebView نمایش می‌دهد. امکاناتی که سایت در مرورگر موبایل ارائه می‌کند ممکن است در WebView نیز در دسترس باشند، اما قابلیت‌هایی مانند انتخاب و بارگذاری فایل، اعلان پوش، لینک‌های پرداخت، ورودهای بیرونی و رفتارهای خاص مرورگر نیازمند آزمون روی دستگاه واقعی و احتمالاً توسعه تکمیلی هستند.

این پروژه از سورس قالب وردپرس استخراج نشده و ادعایی درباره API اختصاصی قالب ندارد.
